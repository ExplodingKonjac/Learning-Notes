# CPU 设计文档

## 设计草稿

设计下面的子模块：

### IFU

取指令单元，内部维护程序计数器 PC 和程序 ROM。输入输出规格如下：

| 名称          | 方向 | 定义           |
| ------------- | ---- | -------------- |
| `clk`         | I    | 时钟信号       |
| `clr`         | I    | 异步复位信号   |
| `we`          | I    | 写使能信号     |
| `wd[31:0]`    | I    | PC 写入数据    |
| `pc[31:0]`    | O    | 当前 PC 值     |
| `instr[31:0]` | O    | 当前取出的指令 |

当 `we` 为 $0$ 时，PC 自增；否则 PC 写入 `wd` 的数据。

### DEC

指令解码单元。输入输出规格如下：

| 名称          | 方向 | 定义                |
| ------------- | ---- | ------------------- |
| `instr[31:0]` | I    | $32$ 位指令码       |
| `opcode[5:0]` | O    | 操作码              |
| `rs[4:0]`     | O    | 操作数 1 寄存器编号 |
| `rt[4:0]`     | O    | 操作数 2 寄存器编号 |
| `rd[4:0]`     | O    | 目标寄存器编号      |
| `shamt[4:0]`  | O    | 移位量              |
| `funct[5:0]`  | O    | 功能码              |
| `imm[15:0]`   | O    | 立即数              |
| `jmm[25:0]`   | O    | J 型指令跳转值      |

每个输出根据 MIPS 指令集规范，利用 Splitter 从 `instr` 中提取。

### GRF

寄存器阵列。输入输出规格如下：

| 名称        | 方向 | 定义            |
| ----------- | ---- | --------------- |
| `clk`       | I    | 时钟信号        |
| `clr`       | I    | 异步复位信号    |
| `we`        | I    | 写使能信号      |
| `rs[4:0]`   | I    | 读 1 寄存器编号 |
| `rt[4:0]`   | I    | 读 2 寄存器编号 |
| `rd[4:0]`   | I    | 写寄存器编号    |
| `wd[31:0]`  | I    | 写入数据        |
| `$rs[31:0]` | O    | 读 1 寄存器的值 |
| `$rt[31:0]` | O    | 读 2 寄存器的值 |

寄存器共 $32$ 个，其中 $\$0$ 寄存器读取值永远为 $0$，写入操作无效。

### DM

数据储存器。输入输出规格如下：

| 名称                 | 方向 | 定义         |
| -------------------- | ---- | ------------ |
| `clk`                | I    | 时钟信号     |
| `clr`                | I    | 异步复位信号 |
| `memStore`           | I    | 写使能信号   |
| `memAddr[31:0]`      | I    | 读写地址     |
| `memStoreData[31:0]` | I    | 写入数据     |
| `memData[31:0]`      | O    | 读出数据     |

内部使用 RAM 实现，通过 Splitter 转化 `memAddr` 位宽。

### CTRL

核心控制器。输入输出规格如下：

| 名称                 | 方向 | 定义                |
| -------------------- | ---- | ------------------- |
| `pc[31:0]`           | I    | 当前 PC 值          |
| `opcode[5:0]`        | I    | 操作码              |
| `rs[4:0]`            | I    | 操作数 1 寄存器编号 |
| `rt[4:0]`            | I    | 操作数 2 寄存器编号 |
| `rd[4:0]`            | I    | 目标寄存器编号      |
| `shamt[4:0]`         | I    | 移位量              |
| `funct[4:0]`         | I    | 功能码              |
| `imm[15:0]`          | I    | 立即数              |
| `jmm[25:0]`          | I    | J 型指令地址值      |
| `$rs[31:0]`          | I    | 操作数 1            |
| `$rt[31:0]`          | I    | 操作数 2            |
| `memData[31:0]`      | I    | 内存读取值          |
| `memStore`           | O    | 内存写使能信号      |
| `memAddr[31:0]`      | O    | 内存读写地址        |
| `memStoreData[31:0]` | O    | 内存写数据          |
| `regStore`           | O    | 寄存器写使能信号    |
| `regAddr[5:0]`       | O    | 寄存器写编号        |
| `regStoreData[31:0]` | O    | 寄存器写数据        |
| `pcStore`            | O    | PC 写使能信号       |
| `pcStoreData[31:0]`  | O    | PC 写数据           |

内部通过对 `opcode` 和 `funct` 的判断，激活对应的指令子电路。

### 顶层模块

按照对应端口，连接 IFU、DEC、GRF、DM、CTRL，并为模块接入统一的时钟信号和复位信号。

## 测试方案

1. 人工测试：使用 MARS 将汇编代码编译为机器码，导入 ROM 中手动测试；
2. 自动化测试：通过脚本调用 Logisim 和 MARS 的命令行接口，实现自动化测试。

## 思考题

1. DM、IFU 发挥储存功能，控制器发挥转移功能；
2. 基本合理。IM 内容不可变，因此使用 ROM；DM 内容可读可写，使用 RAM；GRF 设计上就是寄存器阵列；
3. 无；
4. 因为不加入真值表就是“不进行操作”；
5. 指令覆盖比较完善，但是 `beq` 指令没有测试偏移量为负数的情况。
